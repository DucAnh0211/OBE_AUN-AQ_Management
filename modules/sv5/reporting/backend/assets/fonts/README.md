# Noto Sans

Regular and Bold static fonts from the official Noto font repository:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Distributed under SIL Open Font License 1.1; see `OFL.txt` in this directory.
Embedded by the Reporting PDF exporter to preserve Vietnamese text without
depending on fonts installed on the server.
